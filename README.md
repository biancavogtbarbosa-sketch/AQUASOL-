# AQUASOL — Laboratório Virtual da Piscina Solar

**Slogan:** "Ciência que aquece, inclusão que transforma."

## Sobre o Projeto
O AQUASOL é um site educacional interativo desenvolvido para o Projeto Integrador "Projeto da Piscina". Ele explica a física da radiação solar, a termodinâmica do aquecimento de piscinas e a robótica aplicada (Arduino) para monitoramento de temperatura e luminosidade, com foco total em acessibilidade digital.
